# HTML/CSS HT26 – BE26b

Kursrepo för HTML/CSS-kursen HT26, klass BE26b. Varje lektion/övning ligger i sin egen branch, uppkallad efter lektionen (t.ex. `lesson_01_html`).

## Branches

| Branch | Innehåll |
| --- | --- |
| `lesson_01_html` | Café-webbplats (index, meny, om oss) – dokumentstruktur, rubriker, text, länkar, bilder, listor och attribut |

## Hur man kommer åt en lektion

```bash
git checkout lesson_01_html
```

Öppna sedan `index.html` i webbläsaren (gärna via Live Server i VS Code).
