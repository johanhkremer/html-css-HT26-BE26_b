Välkommen till HTML/CSS

HTML

HTML står för HyperText Markup Language och används för att skapa strukturen på en webbsida. Med HTML beskriver vi vad olika delar av innehållet är, till exempel en rubrik, ett stycke text, en länk eller en bild.

HTML består av element som skrivs med taggar. De flesta element har en starttagg och en sluttagg, till exempel <p> och </p>. Element kan ha attribut som ger extra information, till exempel href på en länk eller src på en bild.

Viktigt att kunna

  • Rubriker skrivs med h1 till h6. Använd bara en h1 per sida.
  • Textstycken skrivs med p.
  • Länkar skapas med a-elementet och attributet href.
  • Bilder läggs in med img-elementet och attributen src och alt.
  • Listor skapas med ul (punktlista) eller ol (numrerad lista) och li.
  • Semantiska element som header, nav, main, section, article och footer beskriver vilken roll innehållet har på sidan.

Exempel

<article>
    <h2>Mitt café</h2>
    <p>Välkommen in på en kopp kaffe!</p>
    <a href="menu.html">Se menyn</a>
</article>

Tips: Tänk på vad innehållet är när du väljer element, inte hur det ska se ut. Utseendet sköter vi med CSS.

CSS

CSS står för Cascading Style Sheets och används för att bestämma hur HTML-innehållet ska se ut. Med CSS kan vi ändra färger, typsnitt, storlekar, avstånd och layout.

En CSS-regel består av en selektor och en eller flera deklarationer. Varje deklaration har en egenskap och ett värde. Om flera regler styr samma sak vinner den mest specifika, eller den som står sist i filen. Det är det som kallas "cascading".

Viktigt att kunna

  • Selektorer väljer vilka HTML-element som ska stylas.
  • Egenskaper beskriver vad som ska ändras, till exempel color.
  • Värden bestämmer hur ändringen ska se ut, till exempel red.
  • Klasser väljs med en punkt (.topic-card) och används när flera element ska se likadana ut.
  • Boxmodellen: varje element är en låda med content, padding, border och margin.
  • CSS skrivs i en separat CSS-fil som kopplas in med link i head.

Exempel

.topic-card {
    border: 1px solid navy;
    border-radius: 10px;
    padding: 10px;
}

Tips: Använd webbläsarens utvecklarverktyg (högerklicka och välj "Inspektera") för att se vilken CSS som gäller för ett element och testa ändringar direkt.

Flexbox

Flexbox är en layoutmodell i CSS som gör det enklare att placera element i en rad eller kolumn. Den är särskilt användbar när innehåll ska fördelas jämnt eller centreras.

Flexbox fungerar i en dimension åt gången. Vi sätter display: flex på föräldern (flex-containern), och då blir alla direkta barn flex-items som placeras längs en huvudaxel och en korsaxel.

Viktigt att kunna

  • display: flex aktiverar Flexbox på föräldern.
  • flex-direction styr riktningen: row (rad) eller column (kolumn).
  • justify-content styr placering längs huvudaxeln.
  • align-items styr placering längs korsaxeln.
  • gap skapar mellanrum mellan elementen.
  • flex-wrap: wrap låter elementen hoppa ner på en ny rad när platsen tar slut.

Exempel

.navbar {
    display: flex;
    justify-content: space-between;
    align-items: center;
    gap: 1rem;
}

Tips: Om du byter flex-direction till column byter huvudaxeln och korsaxeln plats. Då styr justify-content det lodräta och align-items det vågräta.

CSS Grid

CSS Grid är en layoutmodell som används för att skapa rutnät med rader och kolumner. Grid passar bra när en hel sida eller större delar av en layout ska delas upp i tydliga områden.

Till skillnad från Flexbox arbetar Grid i två dimensioner samtidigt, både rader och kolumner. Enheten fr betyder "en del av det lediga utrymmet", så 1fr 1fr ger två lika breda kolumner.

Viktigt att kunna

  • display: grid aktiverar CSS Grid.
  • grid-template-columns skapar kolumner.
  • grid-template-rows skapar rader.
  • gap skapar mellanrum mellan rutorna.
  • repeat(3, 1fr) är ett kortare sätt att skriva 1fr 1fr 1fr.
  • grid-column och grid-row låter ett element sträcka sig över flera kolumner eller rader.

Exempel

.topics {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 1rem;
}

Tips: Använd Grid för den stora layouten på sidan och Flexbox för att placera saker inuti en enskild del, till exempel en meny.

Position

Med egenskapen position kan vi flytta ett element från dess vanliga plats på sidan. Tillsammans med top, right, bottom och left bestämmer vi exakt var elementet ska hamna.

Normalt ligger element efter varandra i det som kallas "normalt flöde". Beroende på vilket värde vi väljer på position stannar elementet kvar i flödet eller lyfts ut ur det, så att andra element beter sig som om det inte fanns där.

De olika värdena

  • static är standardvärdet. Elementet ligger i normalt flöde och top, left med flera påverkar inte.
  • relative flyttar elementet i förhållande till sin vanliga plats. Platsen det lämnade finns kvar i flödet.
  • absolute tar bort elementet ur flödet och placerar det i förhållande till närmaste förälder som har en position (inte static).
  • fixed placerar elementet i förhållande till webbläsarfönstret. Det ligger kvar på samma plats när man scrollar.
  • sticky beter sig som relative tills man scrollar förbi en viss punkt, sedan fastnar elementet, som vår navbar.
  • z-index bestämmer vilket element som hamnar överst när element överlappar varandra.

Exempel

.box-container {
    position: relative;
}

.badge {
    position: absolute;
    top: 0;
    right: 0;
}

Tips: Vill du placera något med absolute inuti en viss låda? Ge lådan position: relative. Annars utgår elementet från hela sidan.

Responsiv design

Responsiv design betyder att en webbsida anpassar sig efter skärmen den visas på, oavsett om det är en mobil, en surfplatta eller en stor datorskärm. Innehållet ska vara lätt att läsa och använda överallt.

Vi arbetar mobile first. Det betyder att vi först skriver CSS för små skärmar och sedan lägger till media queries med min-width som ändrar layouten när skärmen blir bredare.

Viktigt att kunna

  • Meta-taggen viewport i head behövs för att mobilen ska visa sidan i rätt storlek.
  • En media query (@media) innehåller CSS som bara gäller när ett villkor är uppfyllt, till exempel en viss skärmbredd.
  • min-width betyder "från och med den här bredden och uppåt".
  • Brytpunkter (breakpoints) är de bredder där layouten ändras, här 640px och 1024px.
  • Relativa enheter som %, rem och fr anpassar sig bättre än fasta pixelvärden.
  • Bilder kan göras flexibla med max-width: 100% så att de aldrig blir bredare än sin förälder.

Exempel

/* Mobil: en kolumn */
.topics {
    grid-template-columns: 1fr;
}

/* Surfplatta och uppåt: två kolumner */
@media screen and (min-width: 640px) {
    .topics {
        grid-template-columns: repeat(2, 1fr);
    }
}

Tips: Gör webbläsarfönstret smalare och bredare och se hur korten på den här sidan ändras. I utvecklarverktygen finns även ett läge där du kan testa hur sidan ser ut på olika mobiler.
