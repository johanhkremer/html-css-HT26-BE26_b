Välkommen till HTML/CSS

HTML

HTML står för HyperText Markup Language och används för att skapa strukturen på en webbsida. Med HTML beskriver vi vad olika delar av innehållet är.

  • Rubriker skrivs med h1 till h6.
  • Textstycken skrivs med p.
  • Länkar skapas med a-elementet.
  • Bilder läggs in med img-elementet.

CSS

CSS står för Cascading Style Sheets och används för att bestämma hur HTML-innehållet ska se ut. Med CSS kan vi ändra färger, typsnitt, storlekar, avstånd och layout.

  • Selektorer väljer vilka HTML-element som ska stylas.
  • Egenskaper beskriver vad som ska ändras.
  • Värden bestämmer hur ändringen ska se ut.
  • CSS kan skrivas i en separat CSS-fil.

Flexbox

Flexbox är en layoutmodell i CSS som gör det enklare att placera element i en rad eller kolumn. Den är särskilt användbar när innehåll ska fördelas jämnt eller centreras.

  • display: flex aktiverar Flexbox.
  • flex-direction styr riktningen.
  • justify-content styr placering längs huvudaxeln.
  • align-items styr placering längs korsaxeln.

CSS Grid

CSS Grid är en layoutmodell som används för att skapa rutnät med rader och kolumner. Grid passar bra när en hel sida eller större delar av en layout ska delas upp i tydliga områden.

  • display: grid aktiverar CSS Grid.
  • grid-template-columns skapar kolumner.
  • grid-template-rows skapar rader.
  • gap skapar mellanrum mellan rutorna.
